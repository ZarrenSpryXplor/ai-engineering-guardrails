# ASD-STE100 provenance and limitations

Authoritative public source: [ASD Simplified Technical English Maintenance Group (STEMG)](https://www.asd-ste100.org/).

Last project verification: 2026-08-10.

- Current issue: ASD-STE100 Simplified Technical English, Issue 9, released 15 January 2025.
- Status: a controlled natural language and international standard for technical documentation.
- Ownership: ASD owns ASD-STE100. The name is protected by copyright and trademark. This project does not use the ASD logo or redistribute the standard or its controlled dictionary.
- Tools: ASD and STEMG state that they do not endorse, certify, or authorize software tools, including AI-based tools. A tool cannot replace the writer, the standard, or qualified review.

The built-in guidance is ASD-STE100-informed. It is not an ASD-approved or certified checker and does not establish formal ASD-STE100 compliance.

For exact contractual or formal compliance work, [request the current official copy from STEMG](https://www.asd-ste100.org/STE_downloads.html) and use an appropriate qualified review process. Reverify the current issue and [software-tool disclaimer](https://www.asd-ste100.org/STEsoftware.html) before making a formal claim.
